# 💰 Baztami

Baztami is a simple and modern web app that helps users manage their money by adding, tracking, and organizing incomes and expenses.  
It shows your total revenues, expenses, and balance in real time, with data saved automatically in your browser using **localStorage**.

🔗 Live Demo: [baztamiv1.vercel.app](https://baztamiv1.vercel.app)
